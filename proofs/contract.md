# proofs

The facts proved over the built high representation, before any optimisation.

- `proofs.spite`: the entry, `Proofs.Proofs`; it registers each proof in its setup, in order, and its `run` runs them. It declares the `LowProof` kind too.
- `<proof>/proof.spite`: one proof, class `Proof`, with the helpers it needs beside it.

A proof that decides whether code is accepted hands what breaks it to a rule of `validators`; one that only makes code cheaper records its facts for a pass. `../PROOFS.md` lists them.
